# SOP: VA02

## 目的

修改已建立的銷售訂單，例如更改數量、交期、付款條件或新增項目。

## 前提條件

- 已取得 VA02 交易代碼的執行權限
- 已知欲修改的銷售訂單號碼
- 訂單未被其他使用者鎖定
- 確認訂單尚未全數請款（已請款項目無法修改）

## 操作步驟

1. 進入 VA02：在交易代碼輸入框 `wnd[0]/tbar[0]/okcd` 輸入 `VA02`，按 Enter。

2. 輸入銷售訂單號：

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 銷售訂單號（Order） | `wnd[0]/usr/ctxtVBAK-VBELN` | 必填，輸入欲修改的訂單號 | `0000012345` |

   輸入後按 Enter 開啟訂單。

3. 修改抬頭資料（如需）：

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 請求交期（VDATU） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/ssubHEADER_MID:SAPMV45A:4022/ctxtVBAK-VDATU` | 選填，修改整張訂單的請求交期 | `2026/07/31` |
   | 付款條件（ZTERM） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/ssubHEADER_MID:SAPMV45A:4022/ctxtVBKD-ZTERM` | 選填，修改付款條件代碼 | `NT30` |
   | 客戶採購單號（BSTNK） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/ssubHEADER_MID:SAPMV45A:4022/ctxtVBAK-BSTNK` | 選填，修改客戶的 PO 號碼 | `PO-2026-001` |

4. 修改項目（如需）：

   - 在項目 Grid（`wnd[0]/usr/subSUBSCREEN_OVERVIEW:SAPMV45A:4400/subSUBSCREEN_OVERVIEW_BODY:SAPMV45A:4408/cntlCUSTOMER_ITEM_OVERVIEW/shellcont/shell`）直接修改數量、物料或交期。
   - 雙擊項目行可進入項目明細，修改更多欄位（如儲存地點、利潤中心等）。

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 訂購數量（Order Qty） | 項目 Grid 對應欄位 | 選填，直接在 Grid 儲存格修改 | `100` |
   | 物料號碼（Material） | 項目 Grid 對應欄位 | 選填，修改品項物料代碼 | `MAT-001` |
   | 項目交期（Delivery Date） | 項目 Grid 對應欄位 | 選填，修改單一項目的交期 | `2026/08/01` |

5. 新增項目（如需）：在項目 Grid 最下方空白行輸入新物料號碼與訂購數量，系統自動帶入價格與交期。

6. 儲存：點選儲存按鈕 `wnd[0]/tbar[0]/btn[11]`（或按 Ctrl+S），確認狀態列（`wnd[0]/sbar`）顯示「訂單 xxxxxxxxxx 已儲存」。

## 常見問題

| 問題 | 原因 | 處理方式 |
|------|------|---------|
| 訂單已鎖定，無法進入編輯 | 其他使用者正在編輯同一筆訂單 | 等待對方離開後重試，或請系統管理員於 SM12 解除鎖定 |
| 已開立交貨單，無法更改數量 | 訂單數量已被交貨單佔用 | 先在 VL02N 刪除或調整對應交貨單，再回 VA02 修改 |
| 部分項目已開票，不可更改 | 已請款的項目受系統保護無法異動 | 僅能新增項目或取消尚未請款的項目，已請款部分需開立貸項憑單（Credit Memo） |
| 儲存時出現價格錯誤 | 物料價格條件未維護或條件過期 | 至 VK13 確認價格條件，或手動覆蓋價格後再儲存 |
