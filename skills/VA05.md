# SOP: VA05

## 目的

依條件批次查詢多筆銷售訂單，篩選特定客戶、日期範圍或訂單狀態，以監控訂單進度或匯出報表。

## 前提條件

- 已取得 VA05 交易代碼的執行權限
- 知道欲查詢的銷售組織、客戶代碼或日期範圍（至少一個條件）

## 操作步驟

1. 進入 VA05：在交易代碼輸入框 `wnd[0]/tbar[0]/okcd` 輸入 `VA05`，按 Enter。

2. 輸入查詢條件（至少填入一個條件以避免查詢結果過多）：

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 銷售組織（Sales Org.） | `wnd[0]/usr/ctxtSD_VKORG-LOW` | 選填，限定銷售組織代碼 | `1000` |
   | 客戶代碼（Sold-to Party） | `wnd[0]/usr/ctxtSD_KUNNR-LOW` | 選填，輸入售出方客戶代碼 | `CUST001` |
   | 訂單日期 From（Order Date From） | `wnd[0]/usr/ctxtSD_AUDAT-LOW` | 選填，查詢起始訂單日期 | `2026/01/01` |
   | 訂單日期 To（Order Date To） | `wnd[0]/usr/ctxtSD_AUDAT-HIGH` | 選填，查詢結束訂單日期 | `2026/06/30` |
   | 交期 From（Delivery Date From） | `wnd[0]/usr/ctxtSD_VDATU-LOW` | 選填，交期起始範圍 | `2026/07/01` |
   | 交期 To（Delivery Date To） | `wnd[0]/usr/ctxtSD_VDATU-HIGH` | 選填，交期結束範圍 | `2026/07/31` |
   | 訂單狀態（Open Orders） | `wnd[0]/usr/radSD_OFFEN` | 選填，勾選「未結」僅顯示尚未完成的訂單 | 點選選擇 |

3. 執行查詢：點選執行按鈕 `wnd[0]/tbar[1]/btn[8]`（或按 F8）。

4. 查看訂單清單：

   - 結果以 ALV 格式顯示於 Grid `wnd[0]/usr/cntlGRID/shellcont/shell`。
   - 清單欄位包含：訂單號、客戶名稱、訂單日期、請求交期、淨金額、訂單狀態。
   - 雙擊任一筆訂單行，系統跳轉至 VA03 顯示該訂單明細。

5. 返回選擇畫面：點選返回按鈕 `wnd[0]/tbar[0]/btn[3]`（或按 F3）。

## 常見問題

| 問題 | 原因 | 處理方式 |
|------|------|---------|
| 查詢結果筆數過多，畫面顯示警告 | 篩選條件過於寬鬆，命中訂單數超過系統上限 | 加入客戶代碼、日期範圍或銷售組織縮小查詢範圍後重新執行 |
| 找不到特定訂單 | 銷售組織或客戶代碼輸入錯誤，或訂單狀態篩選不符 | 確認銷售組織與客戶代碼後重試，或直接在 VA03 用訂單號查詢 |
| 訂單金額顯示異常 | 幣別或匯率設定問題，或價格條件未正確讀取 | 進入 VA03 明細確認價格條件頁籤，或洽詢 SD 顧問確認設定 |
