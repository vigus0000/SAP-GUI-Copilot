# SOP: MMBE

## 目的
查詢物料在各工廠／儲存地點的庫存數量，涵蓋在途、可用、品質檢驗中、凍結等各類型庫存，適用於庫存盤點確認、出貨前可用量確認等情境。

## 前提條件
- 已登入 SAP GUI，具有 MMBE 執行權限。
- 已知欲查詢的物料號碼（MATNR）；工廠、儲存地點、批次為選填條件。

## 操作步驟

### 一、進入 MMBE

1. 進入交易 MMBE
   - 在 T-Code 欄位（`wnd[0]/tbar[0]/okcd`）輸入 `MMBE`，按 Enter。
   - 系統進入 MMBE 選擇畫面（Stock Overview: Selection Screen）。

### 二、輸入查詢條件

2. 填寫篩選條件（選擇畫面 1000）
   - 依需求填入下列欄位：

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 物料（MATNR） | 欲查詢的物料號碼，對應元素 `wnd[0]/usr/ctxtRM07M-MATNR` | `MAT-100001` |
   | 工廠（WERKS） | 限縮至特定工廠，對應元素 `wnd[0]/usr/ctxtRM07M-WERKS`；選填，留空則查所有工廠 | `1000` |
   | 儲存地點（LGORT） | 限縮至特定儲存地點，對應元素 `wnd[0]/usr/ctxtRM07M-LGORT`；選填 | `0001` |
   | 批次（CHARG） | 限縮至特定批次，對應元素 `wnd[0]/usr/ctxtRM07M-CHARG`；選填，批次管理物料適用 | `BATCH001` |
   | 特殊存貨指示符（SOBKZ） | 限縮特殊存貨類型，對應元素 `wnd[0]/usr/ctxtRM07M-SOBKZ`；選填（例如 K=寄售） | `K` |

   - 物料號碼（MATNR）為必填；其餘欄位留空則系統查詢全部符合資料。

### 三、執行查詢

3. 執行查詢
   - 按 F8 或點選工具列執行按鈕（`wnd[0]/tbar[1]/btn[8]`）。
   - 系統處理後進入庫存概況結果畫面。

### 四、查看結果

4. 閱讀庫存概況樹狀結構
   - 結果以樹狀結構顯示，層次依序為：公司代碼 → 工廠 → 儲存地點。
   - 樹狀控制項位於 `wnd[0]/usr/cntlCONTAINER/shellcont/shell`。
   - 點選各節點左方箭頭可展開，查看該層級下的庫存明細。
   - 主要庫存類別說明：

   | 庫存類別 | 說明 |
   |---|---|
   | 非限制使用庫存（Unrestricted） | 可自由使用的庫存數量 |
   | 在途庫存（In Transit） | 已採購但尚未實體到廠的庫存 |
   | 品質檢驗中（Quality Inspection） | 正在 QC 檢驗中，尚不可使用 |
   | 受限使用（Restricted） | 已標記限制使用的庫存 |
   | 凍結庫存（Blocked） | 被封鎖無法使用的庫存 |

### 五、返回

5. 返回上一畫面
   - 按 F3 或點選返回按鈕（`wnd[0]/tbar[0]/btn[3]`）離開結果畫面。

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 查詢結果空白，無任何庫存顯示 | 物料未在該工廠建立物料主檔，或所有庫存數量為 0 | 確認物料號碼與工廠是否正確；可移除工廠條件查全部工廠 |
| 看不到批次明細或批次欄位無效 | 物料主檔未啟用批次管理（Batch Management） | 確認物料主檔採購/倉儲視圖中批次管理是否已勾選 |
| 特殊存貨（如寄售）查不到 | 未填入正確的特殊存貨指示符（SOBKZ） | 在 SOBKZ 欄位輸入對應代碼（例如 K=寄售、E=訂單庫存） |
| 樹狀節點展開後數量為 0 | 該儲存地點確實無庫存 | 正常現象，確認是否需要改查其他儲存地點 |
