# SOP: MMBE

## 目的
說明如何使用交易代碼 MMBE 進入庫存查詢畫面，並在選擇畫面輸入物料編號（由錄製操作得來的步驟），以便查看指定物料的庫存一覽。

## 前提條件
- 已登入 SAP GUI。

## 操作步驟
1. 進入交易 MMBE — 在 T-Code 欄位（wnd[0]/tbar[0]/okcd）輸入 "MMBE"，然後按 Enter。  
   - 元件 ID：wnd[0]/tbar[0]/okcd

2. 在「物料（範圍下限）」欄位輸入物料編號 — 在畫面（screen 1000）將物料欄位的範圍下限填入 "MAT_002"。  
   - 元件 ID：wnd[0]/usr/ctxtMS_MATNR-LOW  
   - 說明：錄製中使用者將該欄位從 "MAT_001" 改為 "MAT_002"。若該欄位已顯示您欲查詢的物料（例如已為 "MAT_002"），請確認即可，不必重複輸入。

3. 完成上述輸入後執行/按 Enter，確認進入下一畫面（由畫面變換推定） — 錄製顯示系統隨後畫面由 screen 1000 跳轉到 screen 300（標題：選擇 / 庫存一覽表：基本清單）。  
   - 備註（推定）：錄製沒有明確記錄哪一個按鈕被按下或哪個功能鍵被執行，因此在此步驟請按 Enter 或按畫面上的執行/繼續按鈕以提交選擇條件並進入下一畫面。此執行動作為根據畫面變換事件推定。

4. 確認已進入庫存一覽畫面（screen 300）並檢視物料 — 進入後確認畫面上顯示的「物料」欄位值是否為您剛輸入的 MAT_002。  
   - 可確認元件 ID：wnd[0]/usr/ctxtIO_MATERIAL（畫面上「物料」欄位，錄製停止時顯示值為 MAT_002）  
   - 說明：此步僅為確認畫面結果，不屬於使用者輸入動作。

## 待人工確認
- 錄製中未明確記錄用以提交選擇條件的按鈕或功能鍵（例如 Enter、F8、工具列上的「執行/繼續」按鈕或畫面上的「執行」按鈕）。請確認在您系統上應使用哪一個操作來提交選擇並進入下一畫面，或告知欲自動化時應以何種方式模擬此按鍵/按鈕點擊。  
- 若您需要在選擇畫面填入其他條件（例如工廠、儲位、批次等），錄製中未包含這些使用者輸入，請人工確認要額外填寫哪些欄位及其對應值，否則本 SOP 僅包含已驗證的操作。
