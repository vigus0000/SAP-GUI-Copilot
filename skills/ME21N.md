# SOP: ME21N

## 目的
使用交易 ME21N（Enjoy 採購訂單）建立標準採購訂單（PO），可從請購單直接轉換或手動建立，最後儲存並取得採購訂單號碼。

## 前提條件
- 已登入 SAP GUI，具有 ME21N 執行權限。
- 若要從請購單轉換，需有對應的請購單號碼（例如本次錄製使用 10002231）。

## 操作步驟

### 一、進入 ME21N

1. 進入交易 ME21N  
   - 在 T-Code 欄位（`wnd[0]/tbar[0]/okcd`）輸入 `ME21N`，按 Enter。  
   - 系統進入 ME21N 主畫面（Enjoy PO，畫面編號 14，主控制項為 `wnd[0]/usr/shell[0]`）。

### 二、設定文件概觀（從請購單轉換時）

2. 開啟文件概觀（Document Overview）  
   - 在 ME21N 主畫面點選左上角「文件概觀啟動/關閉」按鈕，或使用 Ctrl+Shift+F5。  
   - 畫面跳至「一般選擇」（screen 1000），顯示篩選條件欄位。

3. 輸入請購單篩選條件（screen 1000）  
   - 請購單號碼（From）欄位：`wnd[0]/usr/ctxtSP$00026-LOW`  
     → 輸入或確認請購單號，例如 `10002231`；若系統已預設，沿用即可。  
   - 其他篩選欄位（依需要填入，均為選填）：  
     - 申請人名稱：`wnd[0]/usr/...SP$00045...`  
     - 請購日期（From/To）：`wnd[0]/usr/...SP$00044...`  
     - 採購群組：`wnd[0]/usr/...SP$00031...`  
     - 採購組織：`wnd[0]/usr/...SP$00040...`  
     - 物料：`wnd[0]/usr/...SP$00034...`  
     - 物料群組：`wnd[0]/usr/...SP$00033...`  
     - 工廠：`wnd[0]/usr/...SP$00036...`  
     - 固定供應商：`wnd[0]/usr/...SP$00039...`  
   - 系統預設最大符合項目數為 5000（`wnd[0]/usr/txtP_QCOUNT`），通常不須修改。  
   - 勾選狀態篩選（預設已勾選）：  
     - 僅未結（`wnd[0]/usr/chkP_QERLBA`）  
     - 僅已核發（`wnd[0]/usr/chkP_QFREIG`）  

4. 執行篩選，回到主畫面  
   - 按 F8 或工具列「執行」按鈕，系統依條件列出請購單。  
   - 系統返回 ME21N 主畫面（screen 14），左側文件概觀顯示篩選後的請購單清單。

### 三、建立採購訂單抬頭

5. 設定採購訂單類型（PO Type）  
   - 在 ME21N 主畫面抬頭區確認或選擇訂單類型（例如 `NB` 標準採購訂單）。  
   - 若需更改，點選訂單類型欄位的下拉選單。

6. 輸入供應商（Vendor）  
   - 在抬頭的「供應商」欄位輸入供應商代碼。  
   - 按 Enter 讓系統讀入供應商基本資料（付款條件、交貨條件等）。  
   - 若系統彈出供應商搜尋結果視窗，選擇對應供應商後確認。

7. 確認抬頭組織資料  
   - 採購組織（Purch. Org.）、採購群組（Purch. Group）、公司代碼（Company Code）：  
     確認系統帶出的預設值是否正確；若需修改，直接在欄位輸入正確代碼。

### 四、建立採購訂單項目

8. 在項目概覽（Item Overview）輸入第一個採購項目  
   - 進入 ME21N 主畫面的項目區（Item Overview 表格，`wnd[0]/usr/shell[0]` 內的 Grid）。  
   - 在第一列逐欄填入（以實際值取代 `<>` 內文字）：

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 物料（Material） | 物料編號 | `MAT-001` |
   | 短文（Short Text） | 項目描述（物料無號時必填） | `辦公桌` |
   | 採購數量（PO Qty） | 訂購數量 | `10` |
   | 單位（OUn） | 計量單位 | `EA` |
   | 交貨日期（Deliv. Date） | 請求交貨日期 | `2026/07/31` |
   | 工廠（Plant） | 收料工廠代碼 | `1000` |
   | 儲存地點（Sloc） | 收料儲存地點（選填） | `0001` |
   | 淨價（Net Price） | 單價 | `1500.00` |
   | 幣別（Crcy） | 貨幣（通常自動帶入） | `TWD` |

   - 若目前欄位已有可接受的值，請確認沿用，不須重新輸入。

9. 進入項目明細（如需）  
   - 在項目列點兩下或點選「項目明細」頁籤。  
   - 可在「科目指派」頁籤設定成本中心或 WBS；在「交貨」頁籤確認過欠收容差；在「文字」頁籤新增備註。

10. 新增更多項目（如需）  
    - 在項目概覽區下一空白列繼續輸入；或使用工具列「插入明細項目」按鈕。

### 五、檢查與儲存

11. 執行系統檢查  
    - 點選工具列「檢查」按鈕（`wnd[0]/tbar[1]/btn[39]`，提示：Check），或使用 Ctrl+Shift+F3。  
    - 檢視畫面上方的訊息列，修正所有紅色錯誤後再繼續。

12. 儲存採購訂單  
    - 點選儲存按鈕（`wnd[0]/tbar[0]/btn[11]`，Ctrl+S）。  
    - 狀態列（`wnd[0]/sbar`）出現「採購訂單 45xxxxxxxx 已建立」即表示成功。  
    - 記錄採購訂單號碼以供後續作業（例如 GR 入庫、Invoice Verification）使用。

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 存檔時出現「供應商必填」 | 尚未輸入供應商代碼 | 在抬頭輸入供應商後按 Enter |
| 「採購組織不存在」 | 採購組織代碼錯誤 | 確認採購組織代碼或按 F4 搜尋 |
| 項目明細缺少科目指派 | 科目指派類型（K/F/P）缺欄位 | 進入項目明細→科目指派頁籤補填 |
| 文件概觀篩選無結果 | 請購單號或篩選條件不符 | 清除篩選條件重新執行，或直接輸入請購單號 |

## 補充說明
- 若要從請購單參考轉換：在文件概觀選取請購單後，可將請購行拖曳至右側 PO 項目區，或直接採用系統建議的來源。  
- 若不需文件概觀，可直接在主畫面手動填寫供應商與項目資料。  
- 返回按鈕（`wnd[0]/tbar[0]/btn[3]`）或 F3 可離開當前畫面；取消（`wnd[0]/tbar[0]/btn[12]`）放棄未儲存變更。
