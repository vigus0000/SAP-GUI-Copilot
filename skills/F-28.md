# SOP: F-28

## 目的

將收到的客戶款項（銀行入帳）與對應的應收帳款憑證進行沖銷結清，使帳款狀態由「未結」變為「已清」。

## 前提條件

- 已取得 F-28 過帳授權（授權物件 F_BKPF_BUK）
- 客戶應收帳款憑證已存在且狀態為「未結」
- 已確認收款銀行入帳金額及入帳日期
- 已知對應客戶代碼及銀行科目號

## 操作步驟

1. 進入 F-28：`wnd[0]/tbar[0]/okcd` 輸入 `F-28`，按 Enter

2. 輸入抬頭資料：

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 憑證日期（Document Date） | `wnd[0]/usr/ctxtBKPF-BLDAT` | 收款日期（必填） | `2026/06/24` |
   | 過帳日期（Posting Date） | `wnd[0]/usr/ctxtBKPF-BUDAT` | 過帳日期（必填） | `2026/06/24` |
   | 公司代碼（Company Code） | `wnd[0]/usr/ctxtBKPF-BUKRS` | 公司代碼（必填） | `1000` |
   | 幣別（Currency） | `wnd[0]/usr/ctxtBKPF-WAERS` | 收款幣別（必填） | `TWD` |
   | 銀行科目（Bank Account） | `wnd[0]/usr/ctxtRF05V-NEWKO` | 收款銀行科目號（必填） | `113100` |
   | 收款金額（Amount） | `wnd[0]/usr/txtRF05V-WRBTR` | 實際收款金額（必填） | `50000.00` |
   | 客戶（Customer） | `wnd[0]/usr/ctxtRF05V-GKONT` | 客戶代碼（必填） | `C10001` |

3. 按 Enter 進入「選取開放項目」畫面

4. 查看未結應收款項清單，勾選對應的發票行沖銷：
   - 系統自動標記金額相符的項目；若金額不符可手動點選
   - 確認「差額」欄顯示為 0（完全沖銷）

5. 儲存：`wnd[0]/tbar[0]/btn[11]`（Ctrl+S）
   - 狀態列顯示「已過帳憑證 xxxxxxxxxx」

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 差額不為 0 | 收款金額與發票金額不符 | 確認金額，或分拆部分沖銷 |
| 找不到未結項目 | 客戶代碼錯誤或已沖銷 | 確認客戶代碼，使用 FBL5N 確認帳款狀態 |
| 幣別差異 | 外幣收款與帳款幣別不同 | 在差額欄輸入匯差調整金額 |
