# SOP: 依公司代碼作應負帳款查詢

## 目的
說明如何在 SAP GUI 使用 FBL1N（供應商明細項目顯示）依公司代碼查詢應負帳款（以未結項目為例），包含篩選設定與執行報表的操作步驟。

## 前提條件
- 已登入 SAP GUI 並有執行 FBL1N 的授權。

## 操作步驟
1. 進入交易 FBL1N — 在 T-Code 欄位輸入 "fbl1n" 並按 Enter（欄位：wnd[0]/tbar[0]/okcd）。
2. 在 FBL1N 的選擇條件畫面，設定公司代碼：
   - 定位到「公司代碼」欄位（wnd[0]/usr/ctxtKD_BUKRS-LOW）。
   - 若畫面已顯示正確公司代碼（例如：1710），請確認沿用；若未顯示或需查別的公司代碼，請輸入 "1710"（或欲查詢的公司代碼）。
3. 選擇要顯示的項目類型（以「未結項目」為例）：
   - 勾選／選取「未結項目」選項（radio） — 元件 ID：wnd[0]/usr/radX_OPSEL，將其設為選取 (True)。
   - 確認「已結項目」與「全部項目」選項未被選取：wnd[0]/usr/radX_CLSEL（False）、wnd[0]/usr/radX_AISEL（False）。
4. 設定查詢日期（視需要決定）：
   - 定位到日期欄位（wnd[0]/usr/ctxtPA_STIDA）。
   - 若系統或畫面已提供可接受的日期，請確認沿用；若需指定日期，請輸入欲查詢的日期（錄製時為 "2026/06/11"），再按 Tab 或確定欄位已更新。
5. 設定其他篩選核取方塊：
   - 「一般項目（Normal）」應勾選：wnd[0]/usr/chkX_NORM，設為選取 (True)。
   - 其餘錄製中為未勾選者請保持未勾選：
     - wnd[0]/usr/chkX_SHBV -> False（不勾選）
     - wnd[0]/usr/chkX_MERK -> False（不勾選）
     - wnd[0]/usr/chkX_PARK -> False（不勾選）
     - wnd[0]/usr/chkX_APAR -> False（不勾選）
   - 說明：若畫面上這些核取方塊已為預期狀態，請確認即可，不必重新變更。
6. 執行查詢：
   - 按 Execute（執行）或按 F8 執行報表（或在欄位上按 Enter 以啟動查詢）。
7. 確認查詢結果：
   - 等待畫面跳至結果列表（錄製結果為畫面號碼 120，標題「供應商明細項目顯示」）。
   - 檢查狀態列顯示查詢結果筆數（狀態列元件：wnd[0]/sbar），例如：「4,130 項目已顯示」表示查詢成功並列出項目。
8. 結果後續處理（選用）：
   - 若需匯出、列印或另存，請使用畫面上方功能表或工具列（例如「清單」->「匯出」或工具列按鈕），視需求操作。

補充說明
- 元件 ID 已標注於每一個相關欄位/控制項，方便自動化或系統定位。
- 若畫面欄位為系統預設值或已顯示可接受的目前值，建議「確認沿用」而非強制重新輸入。
