# SOP: MIR6

## 目的

查詢 MIRO 過帳的採購發票驗證文件清單，可篩選狀態、供應商、PO 號等條件，快速定位特定發票憑證。

## 前提條件

- 已取得 MIR6 查詢授權
- 已知要查詢的公司代碼
- 可選擇性提供供應商代碼、採購訂單號或日期範圍以縮小結果

## 操作步驟

1. 進入 MIR6：`wnd[0]/tbar[0]/okcd` 輸入 `MIR6`，按 Enter

2. 輸入查詢條件：

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 公司代碼（Company Code） | `wnd[0]/usr/ctxtRM08M-BUKRS` | 公司代碼（必填） | `1000` |
   | 過帳日期 From | `wnd[0]/usr/ctxtRM08M-BUDAT_FROM` | 查詢起始日（選填） | `2026/06/01` |
   | 過帳日期 To | `wnd[0]/usr/ctxtRM08M-BUDAT_TO` | 查詢結束日（選填） | `2026/06/30` |
   | 供應商（Vendor） | `wnd[0]/usr/ctxtRM08M-LIFNR` | 供應商代碼（選填） | `V10001` |
   | 採購訂單號（PO Number） | `wnd[0]/usr/ctxtRM08M-EBELN` | PO 號碼（選填） | `4500001234` |
   | 狀態（Status） | `wnd[0]/usr/cmbRM08M-SELKZ` | 全部/已過帳/暫停/取消（選填） | `全部` |

3. 執行查詢：`wnd[0]/tbar[1]/btn[8]`（F8）

4. 查看發票清單：
   - ALV Grid 顯示憑證號、供應商、發票日期、金額、狀態
   - 結果 Grid：`wnd[0]/usr/cntlGRID/shellcont/shell`
   - 雙擊任一行可進入 MIRO 查看完整發票明細

5. 返回：`wnd[0]/tbar[0]/btn[3]`

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 查詢無結果 | 日期範圍或供應商代碼錯誤 | 放寬日期範圍，確認供應商代碼 |
| 看不到某筆發票 | 狀態篩選排除了該發票 | 將狀態改為「全部」重新查詢 |
| 發票金額顯示異常 | 幣別轉換問題 | 確認發票幣別與顯示幣別設定 |
