# SOP: ME5A

## 目的
說明如何於 SAP GUI 使用交易 ME5A 查詢特定請購單的列表，並確認查詢結果。

## 前提條件
- 已登入 SAP GUI 並有執行 ME5A 的權限。

## 操作步驟
1. 進入交易 ME5A  
   - 在 T-Code 欄位（wnd[0]/tbar[0]/okcd）輸入 "ME5A"，按 Enter 進入請購單查詢畫面（交易：ME5A）。

2. 在「請購單 (From)」欄位輸入請購單號（若畫面已存在可接受之請購單號，請直接沿用，不需重新輸入）  
   - 欄位：請購單 (From) — 元件 ID：wnd[0]/usr/ctxtBA_BANFN-LOW  
   - 若需輸入，填入請購單號，例如：0010002231

3. 執行查詢以顯示請購單列表  
   - 執行方式：按畫面執行鈕或按 F8（或按 Enter 視系統設定而定），系統會切換至請購單列表畫面（畫面編號 500）。

4. 確認查詢結果（請購單列表顯示）  
   - 結果頁面標題：請購單列表顯示（screen 500）  
   - 列表元件（Grid）：wnd[0]/usr/cntlGRID1/shellcont/shell/shellcont[1]/shell（GuiGridView）  
   - 檢查列表列數與內容，確認是否包含欲查詢之請購單（例如畫面中顯示「請購單 10002231」）。  
   - 如要查看明細欄位，可檢視該 Grid 中的欄位：項目(BNFPO)、物料(MATNR)、短文(TXZ01)、數量(MENGE)、單位(MEINS)、交貨日期(EEIND) 等，確認物料與數量等資訊（範例：MAT_010 / BENQ 24"螢幕 / 10 EA / 交貨日 20260623）。

5. 若需檢視請購單明細（逐筆或展開）  
   - 可使用選單：轉到 -> 請購單明細（wnd[0]/mbar/menu[2]/menu[0]）或在 Grid 上雙擊欲查詢的列以開啟明細（視系統行為而定）。

6. 若查無結果或結果不正確，請確認：  
   - 請購單號格式（是否包含或不含前置零）；  
   - 查詢範圍是否正確（From/To）；  
   - 權限或伺服器回應（可查看狀態列 wnd[0]/sbar 的訊息）。
