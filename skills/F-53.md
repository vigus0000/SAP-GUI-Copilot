# SOP: F-53

## 目的

執行廠商付款，將付款金額與對應的應付帳款憑證沖銷結清，使帳款狀態由「未結」變為「已清」。

## 前提條件

- 已取得 F-53 過帳授權（授權物件 F_BKPF_BUK）
- 供應商應付帳款憑證已存在且狀態為「未結」
- 已確認付款金額及付款日期
- 已知供應商代碼及付款銀行科目號

## 操作步驟

1. 進入 F-53：`wnd[0]/tbar[0]/okcd` 輸入 `F-53`，按 Enter

2. 輸入抬頭資料：

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 憑證日期（Document Date） | `wnd[0]/usr/ctxtBKPF-BLDAT` | 付款日期（必填） | `2026/06/24` |
   | 過帳日期（Posting Date） | `wnd[0]/usr/ctxtBKPF-BUDAT` | 過帳日期（必填） | `2026/06/24` |
   | 公司代碼（Company Code） | `wnd[0]/usr/ctxtBKPF-BUKRS` | 公司代碼（必填） | `1000` |
   | 幣別（Currency） | `wnd[0]/usr/ctxtBKPF-WAERS` | 付款幣別（必填） | `TWD` |
   | 銀行科目（Bank Account） | `wnd[0]/usr/ctxtRF05A-NEWKO` | 付款銀行科目（必填） | `112100` |
   | 付款金額（Amount） | `wnd[0]/usr/txtRF05A-WRBTR` | 實際付款金額（必填） | `105000.00` |
   | 供應商（Vendor） | `wnd[0]/usr/ctxtRF05A-GKONT` | 供應商代碼（必填） | `V10001` |

3. 按 Enter 進入「選取開放項目」畫面

4. 系統顯示該供應商所有未結應付款，勾選本次要結清的發票：
   - 確認「差額」欄顯示為 0（金額完全吻合）
   - 若有折扣或匯差，在對應欄位輸入調整金額

5. 儲存：`wnd[0]/tbar[0]/btn[11]`（Ctrl+S）
   - 狀態列顯示「已過帳憑證 xxxxxxxxxx」

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 差額不為 0 | 付款金額與發票金額不符 | 確認金額，或在「現金折扣」欄位輸入折扣金額 |
| 找不到未結項目 | 供應商代碼錯誤或已結清 | 確認供應商代碼，使用 FBL1N 確認帳款狀態 |
| 銀行科目錯誤 | 付款銀行選擇錯誤 | 確認公司的銀行科目對照表 |
| 無付款授權 | 缺少 F_BKPF_BUK 授權 | 請 SAP 管理員授與付款過帳授權 |
