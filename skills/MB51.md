# SOP: MB51

## 目的
查詢物料在指定期間內的所有異動記錄，包含入庫（GR）、出庫（GI）、轉儲（Transfer）等物料憑證，用於庫存異動追蹤、對帳及稽核。

## 前提條件
- 已登入 SAP GUI，具有 MB51 執行權限。
- 已知欲查詢的過帳日期範圍（必填）；物料號、工廠、移動類型等為選填條件。
- 若查詢範圍較大（跨越數月且未指定物料），建議縮小條件以避免系統超時。

## 操作步驟

### 一、進入 MB51

1. 進入交易 MB51
   - 在 T-Code 欄位（`wnd[0]/tbar[0]/okcd`）輸入 `MB51`，按 Enter。
   - 系統進入 MB51 選擇畫面（Material Documents: Selection Screen）。

### 二、輸入選擇條件

2. 填寫篩選條件
   - 依需求填入下列欄位：

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 物料 From（MATNR） | 篩選特定物料，對應元素 `wnd[0]/usr/ctxtRM07M-MATNR`；選填，留空則查全部物料 | `MAT-100001` |
   | 工廠（WERKS） | 限縮至特定工廠，對應元素 `wnd[0]/usr/ctxtRM07M-WERKS`；選填 | `1000` |
   | 儲存地點（LGORT） | 限縮至特定儲存地點，對應元素 `wnd[0]/usr/ctxtRM07M-LGORT`；選填 | `0001` |
   | 移動類型 From（BWART） | 篩選起始移動類型，對應元素 `wnd[0]/usr/ctxtRM07M-BWART`；選填 | `101` |
   | 移動類型 To（BWART2） | 篩選結束移動類型，對應元素 `wnd[0]/usr/ctxtRM07M-BWART2`；選填（與 From 相同則只查單一類型） | `101` |
   | 過帳日期 From（BUDAT） | 查詢起始過帳日期，對應元素 `wnd[0]/usr/ctxtRM07M-BUDAT` | `2026/06/01` |
   | 過帳日期 To（BUDAT2） | 查詢結束過帳日期，對應元素 `wnd[0]/usr/ctxtRM07M-BUDAT2` | `2026/06/30` |

   - 過帳日期 From（BUDAT）與 To（BUDAT2）為必填，其餘欄位均為選填。
   - 常用移動類型參考：`101`=PO 收貨、`102`=PO 收貨沖銷、`261`=生產領料、`601`=出貨過帳。

### 三、執行查詢

3. 執行查詢
   - 按 F8 或點選工具列執行按鈕（`wnd[0]/tbar[1]/btn[8]`）。
   - 系統處理查詢並進入結果清單畫面。

### 四、查看異動清單

4. 閱讀物料憑證清單
   - 結果以 Grid 表格顯示所有符合條件的物料異動記錄。
   - 結果 Grid 控制項位於 `wnd[0]/usr/cntlCONTAINER/shellcont/shell`。
   - 每列顯示欄位包含：物料憑證號、項目、移動類型、物料號、數量、單位、工廠、儲存地點、過帳日期等。

5. 查看憑證明細（選填）
   - 在結果 Grid 中雙擊任一列，系統跳至該物料憑證的明細畫面。
   - 可查看完整的物料憑證抬頭資訊、參考憑證（PO/生產訂單）及各項目明細。
   - 按 F3 或返回按鈕（`wnd[0]/tbar[0]/btn[3]`）可回到清單。

### 五、返回

6. 返回上一畫面
   - 在結果清單畫面按 F3 或點選返回按鈕（`wnd[0]/tbar[0]/btn[3]`）離開。

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 結果無資料 | 日期範圍內無符合的異動記錄，或移動類型/物料條件過窄 | 放寬篩選條件，先只填日期範圍後執行，再逐步縮小範圍 |
| 執行時間過長或系統超時 | 日期範圍跨度太大且未指定物料或工廠，資料量過大 | 縮短日期範圍，或加入物料號/工廠/移動類型等條件限縮 |
| 看不到某筆異動記錄 | 該異動過帳日期不在查詢範圍內，或以不同移動類型記帳 | 確認過帳日期，或移除移動類型條件重新查詢 |
| 憑證號顯示但數量為 0 | 異動已被沖銷（例如 102 沖銷 101），淨數量相消 | 雙擊進入憑證明細確認原始數量與沖銷關係 |
