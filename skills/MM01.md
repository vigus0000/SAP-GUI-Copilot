# SOP: MM01

## 目的
建立新的物料主檔（Material Master），設定基本資料、採購、MRP、儲存等視圖，使物料可在採購、庫存、生產等流程中使用。

## 前提條件
- 已登入 SAP GUI，具有 MM01 執行權限。
- 已確認物料類型（MARA-MTART）及工業類別（MARA-MBRSH）。
- 已準備好物料描述、計量單位等基本資料。

## 操作步驟

### 一、進入 MM01 並選擇初始設定

1. 進入交易 MM01
   - 在 T-Code 欄位（`wnd[0]/tbar[0]/okcd`）輸入 `MM01`，按 Enter。

2. 輸入物料初始資料

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 物料號碼（Material） | `wnd[0]/usr/ctxtRMMG1-MATNR` | 留空由系統自動編號，或輸入指定號碼（選填） | *(留空)* |
   | 工業類別（Industry Sector） | `wnd[0]/usr/ctxtRMMG1-MBRSH` | M=機械、A=食品等（必填） | `M` |
   | 物料類型（Material Type） | `wnd[0]/usr/ctxtRMMG1-MTART` | ROH=原料、FERT=成品、HALB=半成品等（必填） | `ROH` |

3. 按 Enter 或 `wnd[0]/tbar[0]/btn[0]`，進入「選擇視圖」畫面。

### 二、選擇要建立的視圖

4. 勾選需要建立的視圖
   - 「選擇視圖」清單（`wnd[0]/usr/subSUBSCREEN_VIEWSEL:SAPLMGMM:0060/cntlVIEWS_CONT/shellcont/shell`）
   - 常用視圖建議勾選：

   | 視圖 | 說明 |
   |---|---|
   | 基本資料 1（Basic Data 1） | 物料描述、基本單位（必選） |
   | 基本資料 2（Basic Data 2） | 重量、尺寸等（選填） |
   | 採購（Purchasing） | 採購單位、採購資訊（採購必選） |
   | MRP 1 | MRP 類型、批量程序（生產/採購必選） |
   | MRP 2 | 計畫提前期、安全庫存（選填） |
   | 儲存 1（Storage 1） | 儲存條件（選填） |
   | 會計 1（Accounting 1） | 價格控制、移動平均價（必選） |

5. 確認組織層級
   - 工廠（Plant）：`wnd[0]/usr/subSUBSCREEN_ORGLEVELS:SAPLMGMM:2000/ctxtRMMG1-WERKS`（採購/MRP 視圖必填）
   - 儲存地點（Stor. Location）：`wnd[0]/usr/subSUBSCREEN_ORGLEVELS:SAPLMGMM:2000/ctxtRMMG1-LGORT`（選填）
   - 銷售組織/配銷通路：銷售視圖時必填（選填）

6. 按 Enter 或確認，進入各視圖資料輸入畫面。

### 三、填寫基本資料 1

7. 輸入基本資料（Basic Data 1）

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 物料描述（Description） | `wnd[0]/usr/subSUBSCREEN_DATASCREEN:SAPLMGMM:2004/subSUBSCREEN_MARA:SAPLMGD1:1001/txtMAKT-MAKTX` | 物料中文名稱（必填） | `不鏽鋼螺絲 M6` |
   | 基本單位（Base Unit） | `wnd[0]/usr/subSUBSCREEN_DATASCREEN:SAPLMGMM:2004/subSUBSCREEN_MARA:SAPLMGD1:1001/ctxtMARA-MEINS` | 基本計量單位（必填） | `EA` |
   | 物料群組（Matl Group） | `wnd[0]/usr/subSUBSCREEN_DATASCREEN:SAPLMGMM:2004/subSUBSCREEN_MARA:SAPLMGD1:1001/ctxtMARA-MATKL` | 物料分類群組（選填） | `001` |
   | 舊料號（Old Material No.） | `wnd[0]/usr/subSUBSCREEN_DATASCREEN:SAPLMGMM:2004/subSUBSCREEN_MARA:SAPLMGD1:1001/txtMARA-BISMT` | 舊系統料號或廠商料號（選填） | `OLD-001` |

### 四、填寫採購視圖（選填，採購流程必要）

8. 輸入採購資料

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 採購單位（Order Unit） | 採購時使用的單位（選填，可與基本單位不同） | `BOX` |
   | 採購群組（Purch. Group） | 負責採購的群組（選填） | `001` |
   | 提前期（Planned Delivery Time） | 採購提前期（天數，必填） | `14` |
   | 捨入值（Rounding Value） | 最小訂購倍數（選填） | `100` |

### 五、填寫 MRP 1（選填，庫存規劃必要）

9. 輸入 MRP 設定

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | MRP 類型（MRP Type） | PD=MRP、VB=再訂購點、ND=不規劃（必填） | `PD` |
   | MRP 控制員（MRP Controller） | 負責規劃的人員（必填） | `001` |
   | 批量程序（Lot Size） | EX=精確批量、FX=固定批量（必填） | `EX` |
   | 最小批量（Minimum Lot Size） | 最低採購/生產量（選填） | `100` |

### 六、填寫會計 1（必要）

10. 輸入會計資料

    | 欄位 | 說明 | 範例 |
    |---|---|---|
    | 價格控制（Price Control） | V=移動平均價、S=標準價格（必填） | `V` |
    | 移動平均價／標準價格 | 物料單價（必填） | `50.00` |
    | 幣別（Currency） | 自動帶入公司代碼幣別（自動帶入） | `TWD` |

### 七、儲存

11. 儲存物料主檔
    - 輸入完所有視圖後，按儲存（`wnd[0]/tbar[0]/btn[11]`，Ctrl+S）。
    - 狀態列（`wnd[0]/sbar`）顯示「物料 xxxxxxxxxx 已建立」即表示成功。
    - 記錄系統配發的物料號碼以供後續作業使用。

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 「物料類型不允許此工業類別」 | 類型與類別組合不合法 | 確認公司的物料類型配置清單 |
| 儲存時提示「基本單位不存在」 | 輸入的單位代碼未設定 | 使用 F4 搜尋有效計量單位 |
| MRP 控制員欄位必填提示 | MRP 類型不為 ND 時控制員必填 | 填入有效的 MRP 控制員代碼 |
| 物料號碼重複 | 手動輸入的號碼已存在 | 改用 MM03 查詢，或留空由系統自動編號 |
| 視圖資料無法儲存 | 必填欄位未填 | 依紅色提示補填所有必填欄位 |
