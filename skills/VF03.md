# SOP: VF03

## 目的

以唯讀模式查詢已建立的請款發票明細，確認客戶、金額、付款條件等資訊，並可跳轉查看對應的 FI 會計憑證。

## 前提條件

- 已取得 VF03 交易代碼的執行權限
- 已知欲查詢的請款文件號碼（通常為 9 開頭）；若不知號碼，可先至 VF05 條件查詢

## 操作步驟

1. 進入 VF03：在交易代碼輸入框 `wnd[0]/tbar[0]/okcd` 輸入 `VF03`，按 Enter。

2. 輸入請款文件號：

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 請款文件號（Billing Document） | `wnd[0]/usr/ctxtVBRK-VBELN` | 必填，輸入欲查詢的發票號碼 | `0090012345` |

   輸入後按 Enter 開啟請款文件。

3. 查看請款文件抬頭資訊：

   - 抬頭顯示欄位包含：客戶名稱、請款日期（Billing Date）、總金額（Net Value）、幣別（Currency）、付款條件（Payment Terms）、銷售組織。

4. 查看請款項目明細：

   - 項目 Grid：`wnd[0]/usr/subSUBSCREEN_ITEMS:SAPLVF01:0310/cntlGRID/shellcont/shell`
   - 清單欄位包含：物料號碼、品項描述、帳單數量、計量單位、單價、淨金額。
   - 雙擊項目行可查看更多項目明細，包含價格條件分析。

5. 查看對應的 FI 會計憑證：

   - 透過選單：Environment（環境）→ Account. Documents（會計文件）或按 Ctrl+F8。
   - 系統彈出對話框顯示對應的 FI 憑證號碼（物料憑證、會計憑證等）。
   - 雙擊會計憑證號碼，系統跳轉至 FB03 顯示完整的借貸方分錄明細。

6. 返回：點選返回按鈕 `wnd[0]/tbar[0]/btn[3]`（或按 F3）。

## 常見問題

| 問題 | 原因 | 處理方式 |
|------|------|---------|
| 找不到請款文件號 | 請款文件號輸入錯誤，或文件尚未建立 | 使用 VF05 依客戶、日期或銷售訂單號條件查詢，確認文件是否存在 |
| 「無會計文件」或 Environment 選單中無 FI 憑證 | 請款文件尚未移轉至 FI 應收帳款模組 | 至 VFX3 確認移轉狀態，或手動執行移轉；若仍無法移轉，請洽 FI 顧問檢查移轉設定 |
| 金額顯示為 0 或不正確 | 價格條件（Pricing Conditions）未正確維護，或條件已過期 | 進入 VF03 請款項目明細，點選「Conditions」頁籤確認各價格條件金額，並至 VK13 確認主數據設定 |
| 無法查詢特定請款文件 | 權限不足（Authorization Object V_VBRK_VKO 或 V_VBRK_AAT 受限） | 確認使用者是否具備對應銷售組織的請款查詢權限，必要時請系統管理員調整角色 |
