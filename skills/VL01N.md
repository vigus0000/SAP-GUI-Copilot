# SOP: VL01N

## 目的

依銷售訂單建立出貨交貨單，系統自動帶入交貨品項與數量，確認後可進行揀料與發貨。

## 前提條件

- 已取得 VL01N 交易代碼的執行權限
- 來源銷售訂單已建立且有可交貨項目（交期在選擇日期當日或之前）
- 知道對應的出貨點（Shipping Point）代碼
- 庫存已備妥（庫存不足時仍可建立，但後續過帳會有警告）

## 操作步驟

1. 進入 VL01N：在交易代碼輸入框 `wnd[0]/tbar[0]/okcd` 輸入 `VL01N`，按 Enter。

2. 輸入初始資料：

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 出貨點（Shipping Point） | `wnd[0]/usr/ctxtLIKP-VSTEL` | 必填，輸入出貨點代碼 | `SH01` |
   | 選擇日期（Selection Date） | `wnd[0]/usr/ctxtLV50C-VDATU` | 必填，系統帶入此日期前到期的項目，通常為今日或交期 | `2026/07/31` |
   | 銷售訂單號（Sales Order） | `wnd[0]/usr/ctxtVBAK-VBELN` | 必填，輸入欲建立交貨單的來源銷售訂單號 | `0000012345` |

   輸入完成後按 Enter，系統自動帶入可交貨的品項。

3. 查看系統帶入的品項與數量：

   - 項目 Grid：`wnd[0]/usr/tabsTABSTRIP_OVER/tabpOVER/ssubSUBSCREEN_BODY:VL:4002/cntlDELIVERY_ITEM_OVERVIEW/shellcont/shell`
   - 確認「交貨數量（Delivery Qty）」是否正確；若需部分交貨可直接修改數量。

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 交貨數量（Delivery Qty） | 項目 Grid 對應欄位 | 選填，可修改為部分交貨數量 | `50` |

4. 確認儲存地點（Storage Location）：

   - 雙擊項目行進入項目明細，確認「儲存地點（Storage Location）」欄位已正確帶入。
   - 若未自動帶入，需手動輸入儲存地點代碼。

   | 欄位 | Element ID | 說明 | 範例 |
   |------|-----------|------|------|
   | 儲存地點（Storage Location） | 項目明細對應欄位 | 選填，系統通常自動帶入，視需要手動調整 | `0001` |

5. 儲存：點選儲存按鈕 `wnd[0]/tbar[0]/btn[11]`（或按 Ctrl+S）。確認狀態列（`wnd[0]/sbar`）顯示「交貨單 8xxxxxxxxx 已建立」。

## 常見問題

| 問題 | 原因 | 處理方式 |
|------|------|---------|
| 銷售訂單無可交貨項目 | 訂單已全數交貨，或所有項目交期晚於選擇日期 | 確認訂單狀態，或將選擇日期調整為項目交期當日或之後重新嘗試 |
| 出貨點不正確或找不到 | 出貨點代碼輸入錯誤 | 使用 F4 搜尋有效的出貨點代碼，或洽詢 SD 顧問確認設定 |
| 庫存不足警告 | 指定儲存地點庫存量低於交貨數量 | 可繼續建立交貨單，但需在揀料前先辦理入庫或庫存調撥（MB1B）補足庫存 |
| 找不到銷售訂單 | 訂單號輸入錯誤，或訂單屬於不同銷售組織 | 確認訂單號並在 VA03 查詢確認訂單存在 |
