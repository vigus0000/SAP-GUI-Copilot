# SOP: VA01

## 目的
在 SAP SD 模組中建立標準銷售訂單（Standard Order），記錄客戶對特定物料的採購需求，作為後續出貨、請款的依據。

## 前提條件
- 已登入 SAP GUI，具有 VA01 執行權限。
- 已確認客戶代碼（Sold-to Party）、物料號碼、數量與交貨日期。
- 已知銷售組織（Sales Org）、配銷通路（Distr. Channel）、事業部門（Division）。

## 操作步驟

### 一、進入 VA01 並設定初始參數

1. 進入交易 VA01
   - 在 T-Code 欄位（`wnd[0]/tbar[0]/okcd`）輸入 `VA01`，按 Enter。

2. 設定訂單初始資料（畫面 101）

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 訂單類型 | `wnd[0]/usr/ctxtVBAK-AUART` | OR=標準訂單（必填） | `OR` |
   | 銷售組織（Sales Org） | `wnd[0]/usr/ctxtVBAK-VKORG` | 公司銷售組織代碼（非必填，系統有預設值） | `1000` |
   | 配銷通路（Distr. Channel） | `wnd[0]/usr/ctxtVBAK-VTWEG` | 10=直銷等（非必填，系統有預設值） | `10` |
   | 事業部門（Division） | `wnd[0]/usr/ctxtVBAK-SPART` | 00=跨部門（非必填，系統有預設值） | `00` |

3. 按 Enter 進入訂單主畫面。

### 二、填寫訂單表頭

4. 填入買方資訊

   | 欄位 | Element ID | 說明 | 範例 |
   |---|---|---|---|
   | 買方（Sold-to Party） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/subPART-SUB:SAPMV45A:4701/tabsTAXI_TABSTRIP_HEAD/tabpT\01/ssubSUBSCREEN_BODY:SAPMV45A:4011/ctxtKUNAG-KUNNR` | 客戶代碼（必填） | `CUST001` |
   | 客戶採購單號（BSTKD） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/txtVBKD-BSTKD` | 客戶的 PO 號碼（選填） | `CU-20260101` |
   | 客戶參考（BSTNK） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/ctxtVBKD-BSTNK` | 客戶的參考編號，例如合約號（必填） | `CONTRACT-001` |
   | 幣別（WAERK） | `wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/ctxtVBAK-WAERK` | 系統自動帶入，如需更改再填 | `TWD` |

### 三、填寫品項明細（Item Overview）

6. 切換到「項目概觀」頁籤
   - 點選 `wnd[0]/usr/tabsTAXI_TABSTRIP_OVERVIEW/tabpT\02`（項目概觀）。

7. 在 Grid 中輸入品項資料

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 物料號碼（MATNR） | 必填 | `MAT-001` |
   | 訂購數量（KWMENG） | 必填 | `10` |
   | 出貨工廠（WERKS） | 必填 | `1000` |
   | 要求交貨日（EDATU） | 選填 | `2026/07/31` |
   | 金額／單價（NETPR） | 必填 | `500` |

   - 每行輸入一個品項，按 Tab 或 Enter 移到下一欄。
   - 多品項可繼續在下一行填寫。

### 四、確認與儲存

8. 確認訂單金額
   - 表頭的淨值（Net Value）欄位（`wnd[0]/usr/subSUBSCREEN_HEADER:SAPMV45A:4021/txtVBAK-NETWR`）應自動計算並顯示總金額。

9. 儲存訂單
   - 按工具列儲存鈕（`wnd[0]/tbar[0]/btn[11]`）或 Ctrl+S。
   - 狀態列顯示「訂單 xxxxxxxxxx 已儲存」即表示成功。
   - **記錄訂單號碼**以供後續 VA02（修改）、VL01N（建立出貨單）使用。

## 常見問題

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 畫面停在 101 不跳轉 | 銷售組織/通路/部門未填 | 補填後按 Enter |
| 客戶代碼輸入後提示「不存在」 | 代碼錯誤或無授權 | 按 F4 搜尋，確認客戶代碼 |
| 物料無定價、金額為 0 | 定價條件未設定 | 聯繫 SD 顧問設定定價協議 |
| 儲存後提示不完整（Incomplete） | 必要資料缺失 | 依紅色提示逐一補填 |
| 信用額度超限，訂單被凍結 | 客戶信用不足 | 通知財務放行（VKM3）或調整信用額度 |
