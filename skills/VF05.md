# SOP: VF05

## 目的

依條件批次查詢已建立的請款文件清單（發票、貸項通知單、借項通知單等），用於對帳、追蹤開票進度及確認是否已移轉至財務（FI）模組。

## 前提條件

- 使用者具備 VF05 查詢授權
- 已知查詢條件（至少需輸入請款日期範圍其中一端，或其他縮小範圍的條件）
- 若需查詢特定銷售組織，需確認使用者授權範圍涵蓋該組織

## 操作步驟

1. 進入 VF05：在指令列 `wnd[0]/tbar[0]/okcd` 輸入 `VF05`，按 Enter。

2. 在選擇畫面（Selection Screen）輸入查詢條件：

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 請款日期 From（Billing Date From） | 查詢起始日期（必填其中一端） | `2026/07/01` |
   | 請款日期 To（Billing Date To） | 查詢結束日期（必填其中一端） | `2026/07/31` |
   | 客戶（Customer） | 限定特定客戶代碼（選填） | `C-10001` |
   | 銷售組織（Sales Organization） | 限定銷售組織代碼（選填） | `1000` |
   | 請款類型（Billing Type） | 限定文件類型，如 F2=一般發票、G2=貸項（選填） | `F2` |
   | 未移轉至 FI（Open for Accounting） | 勾選後僅顯示尚未過帳至會計的請款文件（選填） | 勾選 |

   對應 Element ID：
   - 請款日期 From（FKDAT）：`wnd[0]/usr/ctxtVBDKR-FKDAT`
   - 請款日期 To（FKDAT2）：`wnd[0]/usr/ctxtVBDKR-FKDAT2`
   - 客戶（KUNNR）：`wnd[0]/usr/ctxtKUNNR-LOW`
   - 銷售組織（VKORG）：`wnd[0]/usr/ctxtVKORG-LOW`
   - 請款類型（FKART）：`wnd[0]/usr/ctxtFKART-LOW`
   - 未移轉至 FI 核取方塊（TF_OFFEN）：`wnd[0]/usr/chkTF_OFFEN`

3. 執行查詢：點選 `wnd[0]/tbar[1]/btn[8]`（或按 F8）。

4. 查看查詢結果清單：  
   結果 Grid Element ID：`wnd[0]/usr/cntlGRID/shellcont/shell`

   Grid 中顯示所有符合條件的請款文件：

   | 欄位 | 說明 | 範例 |
   |---|---|---|
   | 請款文件號（Billing Document） | 10 碼請款文件號 | `9000012345` |
   | 請款類型（Billing Type） | 文件類型代碼 | `F2` |
   | 請款日期（Billing Date） | 發票日期 | `2026/07/15` |
   | 客戶（Customer） | 客戶代碼 | `C-10001` |
   | 淨金額（Net Value） | 發票金額（未稅） | `150,000` |
   | 幣別（Currency） | 發票幣別 | `TWD` |
   | 會計狀態（Accounting Status） | 是否已移轉至 FI（選填顯示） | `已過帳` |

5. 查看單筆明細（選填）：  
   在結果 Grid 中雙擊任一列，系統自動跳轉至 VF03 顯示該請款文件的完整明細。

6. 返回選擇畫面或主選單：點選 `wnd[0]/tbar[0]/btn[3]`（或按 F3）。

## 常見問題

| 錯誤訊息 / 現象 | 可能原因 | 處理方式 |
|---|---|---|
| 查詢結果筆數過多，畫面緩慢 | 日期範圍過大或條件太寬鬆 | 縮小請款日期範圍（例如改為單週），並加入客戶或銷售組織作為篩選條件 |
| 找不到預期的發票 | 銷售組織或請款類型未填，或發票日期不在查詢範圍內 | 確認銷售組織欄位是否正確填入；嘗試放寬日期範圍重新查詢 |
| 某筆發票會計狀態仍為「未過帳」 | FI 過帳尚未執行，或過帳時發生錯誤 | 雙擊進入 VF03 查看錯誤訊息，或至 VFX3 執行批次 FI 過帳處理 |
| 「無授權」 | 使用者不具備查詢範圍內銷售組織或請款類型的授權 | 聯絡系統管理員擴展查詢授權範圍 |
